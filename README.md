<h1 align="center">ReTran</h1>

<p align="center">ReTran recognizes text on your screen, translates it, and shows the translation on your screen or in OBS.</p>

## Requirements

- Windows 10 or Windows 11, 64-bit.
- 2 GB of free disk space for the CPU version, or 8 GB for the GPU version.
- An internet connection for first-run setup.
- No separate .NET or Python installation is needed.
- An NVIDIA GPU is optional. The GPU version requires NVIDIA driver 576.02 or newer; other computers can use the CPU version.

## Features

- Capture your full screen or an app window.
- Recognize and translate on-screen text in real time.
- Show translations on your screen or through an OBS Browser Source.
- Access common actions from a floating menu.
- Cache translations and translate only new content.
- Translate with online services or local models.
- Use the app in English or Tiếng Việt.
- Keep ReTran up to date with automatic updates.
